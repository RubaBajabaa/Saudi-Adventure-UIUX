# 🎨 Saudi Adventure App – UI/UX Design

A UI/UX design project for a travel and adventure mobile application in Saudi Arabia, created باستخدام Figma.

---

## 🔍 Overview

This project focuses on designing a user-friendly and visually engaging mobile application that helps users explore adventure activities across Saudi Arabia.

The design emphasizes smooth user experience, clear navigation, and attractive visuals.

---

## 🎯 Features

- Explore adventure destinations  
- User-friendly navigation  
- Modern and engaging UI design  
- Interactive prototype  

---

## 🛠 Tools Used

- Figma
- UI/UX Design Principles
